设计标注 · 后台任务侧边栏
1
状态圆点用呼吸脉冲
running 的圆点外圈每 1.9s 扩散一次，表示"仍在运行"；不整行高亮，避免抢占对话区注意力。
2
行内操作只在 hover 出现
停止 / 查看 / 复制默认隐藏，hover 时替换右侧元信息。列表静态态只留"状态 + 描述 + 命令 + 元信息"四件事。
3
「跟随输出」只对运行中任务有意义
激活态用 success 色小圆点，不整条按钮变色；任务结束后自动关闭，避免用户以为还在实时刷新。
4
退出码只染数字，不染整行
退出码 0 用 success 色、非 0 用 destructive 色，行背景保持中性。失败靠图标 + 文字表达，不靠大色块。
5
折叠后保留运行中数量徽标
侧栏收起时 header 上的「后台任务」按钮仍带数量徽标，是唯一的常驻提醒；徽标为 0 时自动隐藏。
