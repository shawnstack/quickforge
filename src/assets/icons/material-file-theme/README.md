# Material Icon Theme assets

QuickForge uses a focused subset of the official Material Icon Theme SVG assets for project file and directory icons.

- Upstream: https://github.com/material-extensions/vscode-material-icon-theme
- Version: 5.36.1
- Commit: `cf0df2b786de4eca01b06cb7118435c6d195a0d1`
- License: MIT
- License copy included in the built application: `/licenses/material-icon-theme.txt`

Only the SVG files referenced by the workspace file browser, Review list, Reader tabs, and artifact UI are included. Operational UI icons such as search, refresh, close, and preview continue to use Lucide.
