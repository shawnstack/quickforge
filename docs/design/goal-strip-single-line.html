规格与取舍

元素规格说明
容器height: 2rem、padding: 0 .375rem 0 .5rem、border-radius: var(--radius)、width: 100%从 fit-content 改占满 composer 宽度：一行内容天然需要整行，居中不确定会让右侧按钮跳动
身份图标14px、--muted-foreground、opacity .85恒定靶心，保持上一轮修好的语义
状态词12px / 600、色 = tone一行内唯一的有色文字
目标12px、单行 ellipsis、flex: 1 1 auto、min-width: 0唯一可伸缩元素；title 保留全文
进度分段条 10×3px ×3 + 2/3（10px）< 560px 只留数字；< 420px 整组隐藏
主操作高 24px、padding: 0 .5rem、实心 tone「暂停 / 继续 / 去处理 / 追加预算」
⋯ 菜单24×24编辑目标 / 打开完整面板 / 轮次与用时 / 清除
动效只有两处：working 的旋转弧（1.1s）、attention 的呼吸点（1.4s）其余全静态；reduced-motion 全部降级
取舍：单行丢掉了什么，怎么补
丢掉补偿
目标两行 → 一行title 全文；需要读全文时点整行开 Inspector
阶段说明（第 3/20 轮 / 暂停于第 3 轮 / 等待工具审批）轮次与用时进 ⋯ 菜单与 title；「等待审批」这类关键信息由状态词「需要你处理」承担
展开箭头 + 就地验收清单分段条 + 2/3 已能回答「还剩几条」；具体哪几条在 Inspector（点整行直达）
