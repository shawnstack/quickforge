QuickForge 动效设计提案

原则：延续「轻盈、克制」的设计语言 —— 快进慢出、小距离位移、统一 120/180/280ms 三档时长、统一 cubic-bezier(0.2,0,0,1) 缓动。退出动画永远比进入快。所有动效尊重 prefers-reduced-motion。

0 · 动效 Token

建议沉淀为 CSS 变量 / Tailwind theme，取代散落各处的 duration-160/200/360。

--dur-fast: 120ms 颜色 / 图标反馈 --dur-base: 180ms 浮层 / 列表项 / toast --dur-slow: 280ms 会话进入 / 大区块 morph --dur-exit: 140ms 所有退出态 --ease-out: cubic-bezier(.2,0,0,1) --ease-spring: cubic-bezier(.34,1.3,.64,1) 仅小元素

1 · 弹窗：淡入 + 轻微上浮（当前是瞬间出现）

遮罩 180ms 淡入；对话框 scale .96→1 + 6px 上浮。不要过大的位移和弹簧感。

2 · 下拉菜单：从触发点展开

transform-origin 设在触发角，scale .95→1 + 4px 位移，180ms。菜单项 hover 只做颜色，不位移。

3 · 列表项：新增进入 / 删除退出 / 选中点脉冲

新项从上方 4px 淡入落位；删除向右 8px 淡出后移除；选中时状态点做一次轻微弹跳。

4 · 消息进入 + streaming 光标

复用已有 conversation-enter 的「opacity .72 + 4px 上浮」，统一到所有新消息；流式输出时行尾用 2px 蓝色光标，不再依赖裸文本。

5 · Toast：轻弹簧进入，快速退出

6 · 侧栏折叠：宽度 + 文字淡出双通道

宽度 220ms 过渡的同时，文字 opacity 提前淡出，避免文字被「挤扁」的廉价感（当前侧栏缺文字淡出通道）。
