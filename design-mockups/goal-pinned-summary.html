状态控制条（输入框上方）摘要主要动作可改目标胶囊

cancelled 已取消隐藏查看结果否（可切换演示或新对话）「已取消」

验收口径统一为「验收标准 3 项」：通过验收 一次性验收当前结果并把 Goal 置为 completed，不做「点一次加一项」的部分验收（无对应生产 API）；也不做逐项勾选，验收标准列表只是清单视图。

编辑与草稿保护

  • 只有 awaiting_confirmation / paused / blocked 允许修改目标；执行中提示「先暂停目标」，待审批 / 待回复 / 待验收提示先处理待办，终态不再提供修改目标（改目标需先切新演示或新建对话）。
  • 草稿（dirty）期间，暂停 / 继续 / 确认执行 / 通过验收 / 继续执行 / 取消目标 / 审批与回答等会丢草稿的跨状态操作被拦住并提示先保存或取消；再次点「修改目标」不会覆盖已有草稿。

键盘与焦点

  • 取消目标弹窗打开后默认焦点落在「返回」（非破坏性动作），Tab / Shift+Tab 在弹窗内循环，Escape 关闭；关闭后焦点回到触发元素，触发元素已隐藏（例如来自摘要更多菜单）则回到工具栏的摘要入口 icon。
  • 控制条与摘要按钮保留 aria-label / title，全局保留 :focus-visible 与 prefers-reduced-motion 降级；摘要面板「更多」按钮保留 aria-haspopup="menu" / aria-expanded。

窄屏（移动）

  • 摘要面板变为弹层：左右 8px、顶部 60px、最大高度 calc(100% - 76px)，面板内部滚动并禁用滚动链传导。
  • 胶囊在窄屏变为聊天区顶部整行紧凑条（短标题 + 状态 + 验收通过数），点击打开弹层；工具栏入口保留。
  • 控制行仍是输入框上方一行，窄屏下状态文字与打开摘要 icon 保持可见，输入框与发送按钮位置不下移。
