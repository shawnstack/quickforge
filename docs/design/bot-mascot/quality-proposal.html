吉祥物质感提案 quality-proposal · 2026-11-13

现状是纯平涂：实心色圆 + 平色眼，任何底上都像「贴纸」，且悬空没有落点。本稿只动质感层——光影、材质、轮廓细节、背景衬托、微交互五个方向，每个方向给出可切换对照与推荐项；13 个状态的动作体系一字不动（质感层是静态叠加，与动作关键帧零冲突）。全部用 SVG 渐变 + CSS 实现，与产品同构（circle r150 + 豆豆眼 rx18/ry32 + 变量换色），对齐后可直接翻译成产品代码。

看稿：每个方向「现状 / 提案 A / 提案 B」对照；微交互区悬停可看动态；文末决策清单勾选 + 落地参数表。无 JS。

要点：渐变在 24–44px 几乎不可见，小尺寸的质感主要靠接触阴影的轮廓兜底（悬空感在小图上反而更明显）；79px 起提案优势逐步展开，160px 是主场。哑光陶瓷是唯一下降到 24px 仍不脏的材质——这也是推荐它的原因之一。

1光影体积感

现状纯平涂。A 只加「上亮下暗」的顶光渐变；B 再加底缘环境反光与接触阴影（球落地）。两张的眼睛都保持纯平，单独看球身变化。

现状 · 平涂

一个平色圆，任何底上都像贴纸，也没有「站在哪」。

A · 仅顶光

左上柔光渐变 + 底部压暗。圆开始有「体积」，但仍悬空。

B · 顶光+反光+落影推荐

B 在 A 上加两件事：底缘环境反光（光从桌面弹回，暗部不死黑）与接触阴影（球「站」在底上）。跳跃/压扁动作时落影留在原地——重量感全靠它，也是 13 个动作最受益的一层。

2材质

在方向①B 的光效基线上换材质，眼睛同步换「釉面」处理：深眼珠（butter/inverse）点白色高光；白眼珠（ink 等）白点不可见，改为冷灰反射 + 底缘内阴影。

现状 · 无材质

数码平涂，无材质信息。

A · 哑光陶瓷推荐

低对比柔光（高光峰值 30%、无镜面），像手办哑光釉。性格中性，8 套配色都稳，24px 缩小不脏。

B · 磨砂玻璃

高光更亮（44%）+ 顶部带状反射 + 半透球身（fill-opacity .94）。科技感更足，但黑球上带状反射不明显，缩小后易显灰。

C · 哑光橡胶

高光宽而弱（大面积泛光）、暗部更深（30%）。像软胶玩具，圆润憨态；缺点是亮色系（tangerine/mint）会显「闷」。

釉面眼对照（butter 深眼珠演示高光点，ink 白眼珠演示冷灰反射）：

现状：平色眼（butter）

釉面：白高光点 + 底缘内阴影（深眼珠）

现状：平色眼（ink 白眼珠）

釉面：冷灰反射 + 底缘内阴影（白眼珠自动换画法）

3轮廓与细节

基线为①B。A 只加「眼窝微凹」；B 再加边缘内阴影与 2.5px 极细暗描边，把「片」封成「体」。用 inverse 白球演示——白球在浅底上边缘融化，是「要不要描边」的试金石。

基线 · ①B

白球 + 纯光影：边缘与浅底几乎融为一体。

A · 眼窝微凹

每只眼外一圈 30×45 暗渐变（峰值 28%，下缘更重）。眼像「嵌」进球里，不是「印」在表面——眯眼/眨眼动作时凹陷感尤其加分。

B · 眼窝+内阴影+细描边推荐

A 基础上：边缘一圈 18% 内阴影贴边收拢体积，再叠 2.5px 暗描边。白球在浅底上终于「立」住；黑球上描边几乎不可见，不碍事。

4背景衬托

质感只有在有对比的底上才看得出来。上排现状、下排推荐组合；三种底：浅色 / 深色 / 透明（棋盘格）。现状墨黑球在深底上靠「深色主题整球反白」兜底，提案的黑球靠自身光影与描边也能立住。

现状 · 浅底

平贴、无落点。

现状 · 深底

黑球接近隐形——现状靠主题反白救场。

现状 · 透明底

GIF/导出场景：没有底色支援。

提案 · 浅底

光影 + 描边 + 落影，稳稳站在浅底上。

提案 · 深底

顶光 + 描边勾勒轮廓；深底上落影可按主题降低（见参数表）。

提案 · 透明底

无底色支援时，描边 + 光影就是全部轮廓信息，比现状强得多。

提案 · inverse

三套质感层（光影/描边/高光）全部是黑白透明渐变，不引入新色相——任意自定义 --body/--eye 都自动成立，8 套预设与自定义色无需逐一调参。inverse 白球是描边收益最大的配色。

6微交互（CSS 示意）

呼吸 3.2s、缩放 2.6%（落影反向呼吸增强「活物感」）；悬浮抬升 20px + 落影变淡变大。落地时叠加在既有动作层之上，不与 13 个状态的关键帧冲突；prefers-reduced-motion 自动关停。

现状 · 静止

待机之外完全静止（产品里 idle 本身有动作，这里只对照质感层）。

提案 · 呼吸

球体 + 落影同时呼吸（一胀一缩），有「活着」的底噪。

提案 · 呼吸 + 悬浮推荐

鼠标悬停试试：轻抬 20px，落影变淡变大——「被托起来」的物理感，与既有 hover 抬眼交互叠加。
