设计说明（独立于产品 UI 的评审脚注）
  • 对照范围：Before 面板逐条复刻 goal-inspector.css 现状值（gap 14 / padding 18 / 13px / anywhere / 裸按钮无 hover），After 为修复提案；两面板共享同一份模拟数据与状态切换。
  • G-01：After 采用 SubagentRunDetailContent 同款滚动容器模式（flex-1 min-h-0 overflow-y-auto + 细滚动条 + overscroll-behavior:contain），并把动作按钮固定在底部动作栏，滚动不丢失。
  • G-02 修正说明：经 src/lib/goal.ts:280-294 谓词核实，当前状态机动作行最多 2 个按钮，340px 下不实际溢出——本示例演示的是健壮性修复（flex-wrap + 按钮 white-space:nowrap + anywhere 收敛到正文），非真实溢出复现。
  • G-03：按钮三层体系 primary/secondary/ghost，含 hover / :active scale(0.97) / focus-visible / transition（--dur-fast）。落地时应直接复用生产 Button 组件变体，而非示例内重写。
  • tone token（C-01）：示例将 #3478d4/#d97706/rgb(4 143 101) 统一声明为 --goal-tone-* 语义变量并提供暗色覆盖；当前生产在 index.css:6823-6827 与 6930 两处重复硬编码。
  • badge 与色块的 color-mix 数值为演示值；按 DESIGN_LANGUAGE L206-219，落地前须经真实界面预览确认不比邻近组件更黑更重。
  • T-A/T-F：一行提示文案为提案（每状态 ≤16 字），机制长句进 ? 浮层；预算改结构化双行 + 进度条 + 「已耗尽」chip，毫秒拼接文案移除。
