ACTION 01
点击终端
先退出工作区全屏，保持右侧工作区展开，再确保全局终端显示在底部。即使终端之前已打开，也不会被误切换成关闭。
全屏关 · 面板开 · 终端开
ACTION 02
点击右侧面板
退出工作区全屏并收起整个工作区；终端状态保持不变。下次重新打开工作区时回到普通侧栏状态。
全屏关 · 面板关
ACTION 03
点击退出全屏 / Esc
只退出全屏，保留右侧工作区和当前标签；按钮、Esc 和关闭路径使用同一个退出逻辑，避免全屏状态残留。
全屏关 · 面板开
