主要改动

先解决“找不到、看不清、不敢批量”，再谈更花哨的能力
01

主从布局，阅读不丢上下文

点击技能在右侧打开详情，列表、筛选和滚动位置都保留；窄屏自动变成抽屉，返回只有一步。

02

搜索与筛选组合

搜索覆盖名称、描述、标签和触发词；来源与启用状态可以叠加筛选，Ctrl K 随时聚焦搜索框。

03

按来源分组，行内降噪

内置 / 个人 / 插件分组，行内只留 1–2 个标签和版本；兼容性、允许工具、路径收进「元数据」。

04

状态可见，批量可撤销

已启用计数常驻顶部；批量启停只作用于当前筛选结果，并能撤销；单行保存有独立进度，不再全局禁用。

05

结构化阅读

概览 / 指令 / 元数据三页；SKILL.md 渲染阅读、可复制，比一整块 pre 更容易定位关键步骤。

06

空状态与搜索路径

没有结果时直接给“清除筛选”；搜索路径从 tooltip 变成可展开、可复制的列表。

范围与取舍

只改前端信息架构，不改 `/api/skills` 的读写语义。 使用次数、热度排序因为目前没有数据源，没有画进来；技能的新增 / 编辑仍然交给文件系统与插件，不在设置页做编辑器。
