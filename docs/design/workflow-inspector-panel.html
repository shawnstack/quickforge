03 · 右侧面板结构

六块，纵向一条滚动流；阶段切换是「局部替换」，不重排整页。

区块内容与现有实现的关系
① 概览 状态 pill · 总耗时 · 规模 · 并发/预算/上限 数据来自 WorkflowRunView 的派生字段（agentCount / toolCount / durationMs / maxAgents…），无需改服务端
② 分段进度 每个阶段一段，宽度等分，颜色 = 阶段状态 由 view.phases 推导，纯展示
③ 阶段胶囊 role="tablist"，可横向滚动；点选切换 ④ 新增本地 state activePhaseIndex，默认 = 运行中阶段 / 首个失败阶段 / 0
④ 阶段明细 Agent 卡（名称 + 状态点 + 工具数 + 耗时 + 「运行详情」按钮）→ 工具行（可展开 input/output） 复用现有 WorkflowAgentRow / WorkflowToolCallRow 的数据与 workflowPhaseSteps 交错逻辑，只换容器样式
⑤ 日志 等宽小字，error 级变红；默认展开 直接用 phase.logs，但改为跨阶段合并（附阶段前缀）
⑥ 结果 / 脚本 两个折叠区，脚本仅 detailed 模式出现 沿用现有 resultPreview / params.script，与聊天内逻辑一致

04 · 复用 run_subagent 的既有链路

右侧打开这件事项目里已经跑通一次（Agent 行 → Inspector 运行详情 Tab），工作流只是把它从「Agent 粒度」提到「整个 run」粒度，不需要新机制。

环节run_subagent 现状run_workflow 新增
触发 <button> → onOpen + dispatch quickforge:open-subagent-run 同样 dispatch quickforge:open-workflow-run（新常量，同一个 window 事件范式）
请求 requestWorkspaceInspector({ kind:'subagent', payload }) requestWorkspaceInspector({ kind:'workflow', payload })，在 workspace-types.ts 的联合里加一个分支
Tab 去重 upsertSubagentRunTab 按 runId 就地替换 upsertWorkflowRunTab 同样按 runId 去重 —— 重复点击只聚焦，不开新 Tab
实时刷新 订阅 subagentRunStore 订阅新的 workflowRunStore（或复用 WorkflowAgentRunEventPublisher 的入口，额外发布 run 级快照）
内容组件 SubagentRunDetailContent（.quickforge-subagent-*） WorkflowRunDetailContent（.quickforge-workflow-detail-*），结构同构
Agent 二级跳转 — 面板内 Agent 卡保留「运行详情 ↗」，再开一个 subagent Tab（已有能力，零成本）

05 · 需要你拍板的三个点

决策 1

聊天内是否彻底取消展开？

推荐：取消。内联展开与右侧详情是同一份数据的两套布局，长期必然漂移（现在 CSS 里已经有两套字号补偿）。 取消后聊天区只剩一行，滚动成本最低。

若担心「用户没发现右侧」，可在首次使用时给一次 1.5s 的入口提示，而不是保留内联展开。

决策 2

阶段切换用胶囊还是纵向全展开？

推荐：胶囊。面板最小宽 340px，纵向全展开时 5 个阶段 + 12 个工具约 1400px 高，需要滚很久； 胶囊把「定位到某阶段」变成一次点击。

代价：失去「一眼看到全貌」。已用 ② 分段进度条补偿。

决策 3

运行中是否自动跟随当前阶段？

推荐：仅首次自动跟随。打开面板时定位到运行中阶段；之后用户手动选了别的阶段就不再抢焦点， 只把胶囊上的状态点更新。

需要记一个 userPickedPhase 布尔，逻辑很小。

实现风险
项说明
Tab 类型要改 5 处 WorkspacePanelTabKind 联合、panelTabMeta/Label/Title、内容分发、PANEL_TAB_ITEMS、持久化白名单 —— 与现有 subagent 完全同构，照抄即可
测试断言 tests/frontend/workflow-renderer.test.ts 有「默认收起」「tool zone 嵌套」「CSS 源码正则」三类断言，取消内联展开后需整组重写
打开态联动 卡片「已打开」需要知道当前 activePanelTab 是不是自己 —— 走 workspaceInspectorOpen + activePanelTabId，需在 ToolMessage 层注入或用一个轻量 store 广播
窄视口 < 1024px 时面板变全屏浮层，卡片点击后整页被盖住；需保证关闭浮层后卡片仍是「已打开」状态，避免误以为丢了
