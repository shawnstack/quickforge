单杠在实心蓝底上就是一枚竖条，用户第一反应是「这是编辑 / 光标」，不是「暂停」。两条杠距 5 格 = 12px 下 2.5px，加 1.2px 描边后净空隙 1.3px，够分辨。

02

现成图标能不能直接用

已装 lucide-react 1.11.0

项目已经装了 lucide-react@1.11.0（main.tsx 里 LucideProvider strokeWidth={1.75}），但有三个坑：lucide 的图标是 stroke-width 由 CSS / Provider 统一控制的、条带按钮强制 stroke-width: 2.4，以及 Pause 用的是 rect 而不是两条 line。

候选：在同一个 24px 蓝底按钮里看
图标12px 渲染来源12px 下的问题结论
现状（单杠） 自绘 只有一条 → 不是暂停 bug
自绘双杠 自绘（= 设计稿） 无 推荐
Pause lucide-react 是两个描边矩形：12px 下每个只有 2.5px 宽、含 1.2px 描边，空心部分剩 0.1px → 糊成两个实心块，还带上下横边，像「日」 不用
CirclePause 的两条线 lucide-react（去圆） 线长只有 6 格（= 3px），比现状还短；且必须自己拆出 circle 不如自绘
SquarePause lucide-react 外框在 12px 就是一圈 1.2px 的方框，把两条杠框死 不用
Play（对照 resume） lucide-react 圆角三角、fill:none 下是空心轮廓；现在自绘的 M8 6.5 17 12l-9 5.5Z 是尖角三角，两者风格不同 可选统一

核心原因：条带的主操作按钮是 24px 命中区里塞 12px 图标、强制 stroke-width: 2.4。lucide 的图标是按 24px 显示设计、stroke-width: 2 的，纵向缩小一半后描边相对变粗，凡是「靠留白分隔两个小形状」的图标（Pause 的 rect、SquarePause 的框）都会糊。所以这个尺寸下只有两条线（line / path）的组合安全。
