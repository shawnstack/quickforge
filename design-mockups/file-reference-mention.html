设计说明

信息架构

  • @：仅引用当前项目文件；插件与目录不出现在 @ 菜单。
  • /：动作、技能与子智能体。
  • +：附件；“+ → 能力”仅作入口关系示意。
  • 设置：插件的安装、启用与管理。

默认推荐

  • 结构化 chip（推荐）：移除活动 @token，引用与正文分离，支持多文件、去重和单独删除。
  • 内联文本只用于对比，直观但难以稳定表达引用身份、去重及删除边界。

MVP 范围

  • 当前项目文件；裸 @ 显示最近项，输入 2+ 字符搜索，最多约 8 条。
  • 键盘/鼠标选择、匹配高亮、加载/空/错误状态、亮暗主题。
  • 不含目录浏览、插件项、跨项目文件、真实文件 API 或权限实现。

待用户确认

  • 是否确认 chip 为默认且唯一的正式呈现？
  • 搜索范围是文件名 + 完整相对路径，还是优先文件名？
  • 裸 @ 的“最近”按打开、编辑还是引用历史排序？
  • 发送后的消息中是否继续显示文件 chip？
