QuickForge 动效设计提案 · 第二批

目标：toast / 菜单展开 / 列表项 enter-exit / 大弹窗复用。延续第一批 token（120 / 180 / 280ms + 统一缓动），本批新增 --dur-exit: 140ms——第一个真正的「进入 + 退出」配对。退出永远比进入快。

1 · 大弹窗复用（skills / GitGraph / Share 同构）

与 ui 弹窗完全相同的进入类：遮罩淡入 + 面板 scale .97、上浮 4px。大弹窗也不做更慢更炫的处理——同一范式，同一节奏。GitGraph 的背景模糊随遮罩一起淡入。

2 · 菜单展开：从触发角生长（左右两例 + 新旧对比）

transform-origin 设在触发按钮一侧的顶角，scale .96→1 + 上浮 4px，180ms。关闭保持瞬时。右侧「当前效果」即现状——瞬间出现。

3 · Toast：进入 180ms，退出 140ms

只过渡 translate + opacity（不再 transition-all）。进入从右侧 16px 滑入淡入；退出更快收回（140ms），堆叠时后方的卡片自然顶上。点卡片或 ✕ 手动关闭，或等 3.2s 自动退出。

4 · 列表项 enter：变更文件列表

agent 运行中文件增删最频繁的列表。新增行 opacity 淡入 180ms 落位（不位移，避免 overflow 容器内裁切）；消失保持瞬时——文件状态本来就由 git 刷新驱动。hover 操作按钮浮现逻辑不变。

5 · 可选：侧栏删除退出 360ms → 140ms

现有会话删除退出 360ms（含收缩），在「退出要快」的刻度下偏慢。左列为现状，右列为 retune 后。两列各点一次删除对比手感。
