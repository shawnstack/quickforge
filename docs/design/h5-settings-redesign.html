手机端设置页交互演示：① 图标宫格导航取代横向滑动胶囊条 · ② 搜索联动内容区 · ③ 切换 tab 滚动复位 + 宫格常驻 · ④ 内容区触控适配。 右侧手机可交互：点宫格切 tab、输入关键词看搜索联动、滚动内容区出现「回到顶部」。

外观 i

可交互演示：点宫格切 tab · 搜索联动 · 滚动出现「回到顶部」

1

图标宫格导航

3×5 宫格，15 项一览可见，取代横向滑动胶囊条。选中项浅蓝高亮，header 标题与图标同步。

2

搜索联动内容区

输入关键词时，宫格过滤且内容区自动切到第一个匹配 tab；无结果显示空态，不残留旧内容。可在手机里试搜「备份」「定时」。

3

切换复位 + 常驻导航

切换 tab 内容区滚动归零（scrollTop=0）；宫格固定不随内容滚动，任何时候都能再切。可选：滚动后右下角「回到顶部」。

4

内容区触控适配

设置行纵向堆叠：标题在上、控件全宽在下；segmented 均分整行、slider 撑满；触控目标 ≥44px（沿用现有 CSS 适配，不动 Lit 渲染）。

现状：横向滑动胶囊条

  • 搜索只过滤 tab 条，内容不联动
  • 滚到底后切 tab 需先滚回顶部
