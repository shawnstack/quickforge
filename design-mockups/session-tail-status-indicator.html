修复 Android 后台轮询耗电 运行中
本方案：状态移到行尾部，并区分"运行中 / 已完成未读"

状态图例

运行中 — 会话后台任务仍在执行，尾部显示 12px 旋转 loader（对应 Loader2 + animate-spin，替代原"标题前绿点"）。
已完成 · 未读 — 任务结束且用户还没看过这个会话，尾部显示 6px 绿点 + 淡光环；点击进入会话即清除。
已读 / 空闲 — 无状态，槽位保留占位保证标题右对齐基线不跳动。

交互说明

  • 状态槽固定 14px，位于时间列右侧（行最尾），四类渲染路径（置顶 / 分组 / 全局 / 搜索）统一追加。
  • hover 出现"置顶 / 归档"操作浮层时只覆盖 pin + 时间 区域，状态槽浮于其上不消失——运行中或未读状态在 hover 时仍可见。
  • 点击会话 = 选中 + 标记已读：绿点消失，spinner 也随任务状态由后端 sessionTaskStatus 驱动消失。
  • 顶部「模拟：后台任务结束」可把所有 spinner 变为绿点，试试点击会话后绿点清除的效果。
  • 遵守 prefers-reduced-motion：减弱动画时 spinner 放慢而非禁用，保留状态可辨识性。
