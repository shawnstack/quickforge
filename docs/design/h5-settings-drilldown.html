说明
插件以独立包形式安装在数据目录。启用/停用即时生效，无需重启。
安装第三方插件前请确认来源可信。
可交互演示：点宫格图标 → 推入二级页；← 返回主菜单
1

主菜单页（设置首页）移动端

顶部保留「返回工作区」与搜索框；中部为一行一项的设置列表（图标 + 名称 + 右侧 › 箭头）， 与手机系统设置菜单一致，整列可上下滚动。搜索只过滤列表项，不再自动跳转内容； 清空搜索恢复全部。点击任一行 → 推入二级页。

2

二级页（单个 tab 内容）移动端

全屏页面：顶部返回箭头 + tab 标题 + 描述信息（同桌面标题行）；下方内容区上下滑动， 保持现有「回到顶部」悬浮按钮。进入时内容滚动复位到顶部，返回后主菜单滚动位置与搜索词保留。 推入/退出带轻微 translateX 转场，符合手机 App 直觉。

3

桌面端零影响 ≥768px

所有移动端双页面结构仅在 md:hidden 容器内；桌面端继续使用 aside（左导航）+ main（右内容）同屏布局， 搜索联动内容区自动切换等现有行为完全不变。

4

实现要点

tab 的 Lit 自定义元素仍单实例挂载（复用现有 SettingsTabHost）， 二级页与桌面端共用同一个内容区容器，仅用 CSS 控制显隐，避免元素重复挂载。 移动端新增一个「当前是否处于二级页」状态（mobileDetail: null | index）驱动两页切换。
