02 · 4 处裁切的成因与修法

#现象成因修法
1 条形贴右边缘时右侧被切一条 项目没有全局 box-sizing: border-box，条形 width: X% 之外再加 1px 边框 → 总宽超出轨道 2px 条形显式 box-sizing: border-box
2 耗时数字伸出轨道被裁 .bar-value 是条形的子元素，left: calc(100% + 5px) 相对条形算，条形靠右必然溢出 移到绘图区，right: 0 固定在右侧安全区
3 「并行」标签盖住左侧行名 同样挂在条形上，right: calc(100% + 5px) 往左伸进标签列 移到绘图区，left: 0 固定在左侧安全区
4 首尾刻度文字被切一半 translateX(-50%) / -100% 需要半个字宽的空间，轨道边界处没有余量 刻度也在绘图区内，安全区同时容纳首尾文字

03 · 一个容易踩的坑

做法为什么不行
给轨道加 padding 当安全区 绝对定位元素的百分比基准是包含块的 padding box（含 padding）， 所以 left: 0% 仍从 border 内侧算起 —— 条形会直接压到左侧安全区里的「并行」标签上。 必须用独立的 plot 层 + margin 来收缩真正的定位基准。
直接把文字改成 hover 才显示 能藏住问题但没解决「条形贴边时自身被切」，且丢失了常驻的耗时信息。
