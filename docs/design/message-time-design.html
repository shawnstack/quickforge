消息时间显示 · 设计稿

在现有消息底部图标行内加入时间：用户消息时间在最前（左端），AI 回复时间在最后（右端）。格式为「月-日 时:分」（如 08-07 10:32），静态显示、无 hover 提示。

用户消息

时间在图标行最前面：气泡右下方的图标行中，时间作为第一个元素，复制 / 回滚 / 重试图标依次排在后面。

AI 回复

时间在图标行最后面：内容左下方的图标行中，复制 / fork 图标在前，时间作为最后一个元素收尾。

规格

弱化小字：12px，颜色为 muted-foreground 55% 透明度混合（与侧边栏会话时间一致）；格式「月-日 时:分」，静态显示。

时间样式规格

字号 / 行高12px / 1（比正文 14px 更弱）
颜色muted-foreground × 55%（同侧边栏会话时间）
数字tabular-nums，避免数字宽度跳动
格式「月-日 时:分」（08-07 10:32），静态显示，无 hover 提示
间距左右 padding 6px，与图标保持 2px 间隙

放置规则

用户消息时间 = 图标行第一个元素（最前）
AI 回复时间 = 图标行最后一个元素（最后）
streaming 中AI 消息无时间戳，不显示时间
readOnly 分享页用户消息无操作图标时，时间仍独立显示
数据来源消息自带 timestamp 字段，无需新增数据结构
