实现要点（对应真实代码）：
① 数据源：server-agent.ts 的 SseConnectionStatus.reconnecting 增加 unreachableSince? 时间戳（探测确认不可达时写入，恢复时清除），UI 据此计算断开时长与 30s 升级阈值（UNREACHABLE_STRIP_AFTER_MS = 30000）。
② Tier1：reconnect-notice.ts unreachable 分支改双行布局 + 琥珀标题 + 「立即重试」按钮（复用 .quickforge-reconnect-retry，点击调既有 requestSseReconnectNow()，重置退避立即重连）；新增 data-state="unreachable" 样式（index.css，琥珀 color-mix 配方同 failed 态）。
③ Tier2：ChatPanelHost 在 composer 上方挂常驻条 controller（挂载/同步方式同现有 panel-decoration 周期 sync()）；样式复用 persist-degraded 的琥珀配方（index.css:2640-2660：35% 边框 + 8% 背景）；恢复指引按运行环境只显示对应一条动作 + 日志行（精简为两行：isDesktopApp() → 重启应用；isNativeMobileEntry() / 远程 → 检查 Tailscale；默认 CLI → qf restart）。
④ 恢复：connected{restarted} 显示时长分档（普通 2.2s / restarted 4s）；状态条走既有 320ms 离场动画。
⑤ i18n 新增 key（中英成对，风格沿用 sseReconnect*）：sseUnreachableTitle、sseUnreachableDetail、sseUnreachableStripTitle、sseUnreachableHelpToggle、sseUnreachableHelpCli/Desktop/Remote/Logs。
⑥ 动画遵循 180ms 进入 / 320ms 离场 + prefers-reduced-motion 全关；Side Chat 与分享页不挂（同现状）。
⑦ 演示时间轴压缩：mockup 中 3s ≈ 实际 30s 升级阈值。
