本稿变更点（对齐讨论用）

前两项为指定必改；其余为建议项，均可在顶部勾选实时对比。

  1. ± 统计红绿着色必改 —— 复用应用现有 diff token（.quickforge-diff-stats-add/del：亮色 rgb(21 128 61)/rgb(185 28 28)，暗色 green-300/red-300），折叠头与行内统计同源，tabular-nums 等宽数字。
  2. 宽度对齐对话必改 —— 卡片从 min(100%, 620px) 改为填满消息容器（width:100%，容器本身受 min(56rem, 100%−2rem) 约束），单文件卡 / 聚合卡 / 正文 / 输入框四者同边。勾选「对齐参考线」看虚线。
  3. 折叠头排版建议 —— 「N 个文件已更改」居左，±统计+撤销推到右侧成组；流式更新时 +N 增长只推右侧统计、不挤压标题。
  4. ± 比例条建议 —— GitHub 风格 5px 双色条（段宽按 +N/−N 占比 flex 分配，红绿各 80% 不透明度），纯新增文件只有绿段。纯新增、纯删除、混合一眼可辨；嫌吵可关。
  5. 按钮 Ghost 化建议 —— 打开/审查/撤销从描边按钮改为无边框 ghost（muted 色、hover 浮底），更接近截图的轻量观感；撤销 hover 转红提示破坏性。取消勾选可回到当前描边样式对比。
  6. 展开动画建议 —— 明细区用 grid-template-rows 0fr→1fr 过渡展开（比 max-height 稳定，无内容高度测量），prefers-reduced-motion 关闭。
