后台任务面板 · 对齐校验

左侧是真实 background-tasks.css 的渲染结果，红线是 0.875rem 基准线，蓝线是输出区内部 0.5rem 缩进线。

本次修正

  • 统一水平基准：header / toolbar / detail-header / meta / output 外框全部落在 0.875rem，与 workflow-detail 同级面板同轴，切 tab 不再横跳 5px。
  • 正文字号升档：面板内正文统一 0.75rem，标题 0.875rem（原来 0.6875rem 的正文过小）。
  • 控件同高：分段控件 1.375rem + 容器 0.125rem 内距 = 搜索框 1.625rem，工具栏内无 1px 高低差。
  • 元信息与操作不再互相压字：两者共用网格第三列，第三列预留 3.5rem，靠透明度交换而不是绝对定位覆盖。
  • 空间节奏回到 1/16 网格：0.375 / 0.5 / 0.75，去掉 0.3 / 0.35 / 0.4 / 1.6 这类零散值。
  • 命令单行截断：长命令不再换行把复制/停止按钮挤到中间；完整值挂 title。
  • 详情区加了分隔线与 padding-bottom，命令与元信息不再贴在一起。
  • 输出区最低 4rem：面板被压矮时不会把日志挤成 0 高。
  • 输出区封顶 18rem（≈14~16 行 + 标题条 + 底部提示）：按内容高度占位、不再 flex: 1 撑满详情区，长日志不会再被拉成半屏、把任务列表挤到只剩两行；超出部分在输出框内滚动，省下的空间归任务列表。
  • 筛选无结果单独提示，不再复用「选择一个任务」空态文案。
  • 触摸目标：pointer: coarse 下图标按钮提到 2rem。

入口

  • 唯一入口是 Composer 左下角的命令图标（终端图标 + 运行中数量角标）。点击不再弹浮层，直接打开右侧面板。
  • 链路：图标 → dispatchOpenBackgroundTasks()（src/lib/background-tasks-open.ts）→ App 监听 quickforge:open-background-tasks 并按 sessionId 过滤 → requestWorkspaceInspector({ kind: 'background-tasks' })。
  • 顶栏没有后台任务按钮；停止与查看日志只在面板内，不存在第二套操作路径。

核对方法

  • 切换「基准线」，看所有内容的左缘是否都压在红线上（列表正文比红线多一个圆点+间距，这是 bullet 缩进）。
  • 鼠标移到任一列表行，元信息应原地淡出、操作按钮原地淡入，不发生位移。
  • 切到 340px 宽度，检查长命令、日志提示是否仍然单行截断而不破版。
  • 切暗色，确认选中行底色、状态圆点、stderr 红字都有足够对比度。

仍然已知的取舍

  • 选中行不显示行内操作（与元信息同格）；停止/复制在详情区里。
  • 日志预览仍是 2s 轮询，不是流式。
  • tab 条上的标签不显示任务数，计数在 Composer 图标的角标与面板头。
