已移除
− 刻度轴 − 时间条 − 并行括线 − 图例 − 子 Agent 过程

为什么删

  • 420px 面板里绘图区只剩约 53px，条形无法横向比较。
  • 22px 轨道与 18px 文字行盒不同心，条形天然低约 2px。
  • 刻度、并行标签、图例抢同一条右缘，最后只能叠字。

改动要点

  1. 01概览两条线：状态、总耗时、规模；并发与失败定位在第二行。图例不再存在。
  2. 02阶段头负责分段：状态点 + 编号 + 标题 + 步数；吸顶保留上下文，字段可折叠。
  3. 03步骤行拿回全宽：时间轴整列移除；耗时数字是可选列，默认隐藏。并行只保留首行文字标记。
  4. 04层级只动内容列：工具行缩进 18px，连接线落在 Agent 图标中心 21px；耗时列不缩进。
  5. 05Agent 行只做入口：保留点击打开对应子 Agent 运行详情；不在 workflow 详情里显示 subagent 的当前工具跑马灯、内部工具或思考过程。queued 保持禁用；workflow 自己的 tool() 行仍保留。
  6. 06失败可定位：概览给「1 个失败步骤 · 定位」；点击滚动并闪烁失败行，替代红色条形。
  7. 07日志降为折叠行：时间 / 消息两列，错误只染消息；不再套描边控制台。
  8. 08底部操作弱化：脚本 / 结果改成低强调文字按钮，去掉整条灰色工具条。
保留 阶段耗时 · 步骤耗时 · 并发 4 · 比串行快 6.2s · Agent 点击跳转。数字不是时间轴，只是一列可开关的对齐元数据。
A

内容优先

隐藏耗时后，420px 下内容列从约 247px 提升到约 372px；显示耗时也有约 324px。文件名和标签先被保住。

B

数字有列

打开耗时后，阶段耗时与步骤耗时共用同一右缘；等宽数字、右对齐，没有轴、没有条形。

C

层级只动内容

工具行只缩进内容列；连接线落在真实图标轴上；耗时列和尾部箭头保持整页对齐。

D

失败可定位

概览给失败计数与定位入口；点击滚动并闪烁失败行，用状态与文字替代红色条形。
