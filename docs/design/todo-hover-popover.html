收拢形态备选

2/5
A. 环 + 计数 推荐
沿用现在收拢态的视觉，只去掉「默认展开」：信息量最小，不抢输入框注意力，进度一眼可读。
调整 todo-summary.css 的浮层定位… 2/5
B. 环 + 当前任务 + 计数
收拢态就能看到正在做什么，代价是胶囊变宽、单行截断，会跟输入框抢一点注意力。

交互契约

  • 默认形态收拢。不常驻任务列表：旧的 useState(true) 改成 false，新快照到达也不再自动展开。
  • 展开触发:hover / :focus-within（键盘 Tab 到胶囊即展开）+ 触摸端点击切换。不用mouseenter 也能工作，CSS 负责状态。
  • 收拢触发指针离开胶囊与浮层后 100ms 宽限再淡出（宽限期内指针移进浮层则不收），离开即收，不做「点击别处才关」。
  • 桥接区胶囊与浮层之间 6px 空隙由浮层的 ::after 覆盖，指针穿过时 hover 不断链。
  • 内容只有任务行：状态图标 + 任务文本。去掉标题、completed/total 统计文案、每行「已完成/进行中/待执行」标签与「已更新」标记。
  • 位置position: absolute; bottom: calc(100% + .375rem) 锚在胶囊正上方，向上弹出，不挤压落款输入区（不改变 dock 高度，避免输入框跳动）。
  • 层级浮层 z-index: 30；实现时确认 composer dock 及祖先没有 overflow: hidden 裁掉浮层（必要时提到 TodoWriteSummary 外层再定位）。
  • 动效进入 --quickforge-dur-base（180ms）：淡入 + 上移 3px + 0.985→1 缩放，origin 在底部；退出 --quickforge-dur-exit（140ms）。全部引用 motion token。
  • 降级prefers-reduced-motion 下取消位移/缩放，仅保留显隐；触摸端无 hover，靠点击。
