同一根时间轴、同一套状态点，日志贴在产生它的阶段下

原型（可直接滚动、展开、切宽度）

滚轮在面板内滚动：刻度条吸顶，阶段标题吸顶，点工具行展开入参/输出，点阶段标题折起整个阶段。

要点

  • 为什么能合并：三个 tab 本来就是同一份数据的三种投影 —— 时间轴读 startOffsetMs / durationMs，阶段读 phases[]，日志读 logs[]（每条自带 phase）。合并后一份数据只渲染一遍，不再切三套 DOM。
  • 结构：阶段小节 = 阶段头（编号/名称/步数/耗时）+ 该阶段的行（Agent 行带条形，工具行缩进带 1px 从属线）+ 该阶段的日志。整页共享一根时间轴，条形因此可以跨阶段横向比较。
  • 只有两个吸顶元素：刻度条（--axis-h）与阶段标题（top: var(--axis-h)）。长列表里随时知道"我在第几个阶段、现在滚到第几秒"。
  • 去掉了三段控件：role="tablist" 的分段按钮、aria-selected、选中态背景一起删除；面板顶部省掉一整行，垂直空间还给内容。
  • 日志不再整页平铺：运行级日志（不属于任何阶段）才单独落在末尾的「运行日志」小节 —— 出现频率低，所以不做折叠。
  • 保留的渐进展开：工具行入参/输出、阶段折叠仍然是"点一下展开"，这是层级渐进而非视图切换，符合 DESIGN_LANGUAGE.md「层级渐进」「整行可点时不另摆入口提示」。
  • 可复用现有 CSS：-row / -plot / -bar / -axis / -phase / -agent / -dot / -pill 都能沿用；实际改动主要是删 -seg 与 -pane 的三视图分发，把 TimelineView 与 PhaseView 合成一个按阶段分组的渲染函数。
