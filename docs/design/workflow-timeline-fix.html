03 · 容器约束（「显示不全」的第二个原因）

时间轴本身修好后还有一个问题：详情根节点没有 flex: 1，作为 Inspector 内容区（row-flex）的子项会按内容收缩， 轨道被压成一条窄缝；同时 height: 100% 在父级高度为 auto 时解析失败，pane 的 overflow-y: auto 不生效，内容被父级 overflow: hidden 直接裁掉。

04 · 一并修掉的 3 个 token 缺陷

缺陷原因修法
文字/条形太小 SVG viewBox="0 0 1000 H" + width:100% 会等比缩放整张图，字号跟着缩 改成 DOM + 百分比定位；标签列固定 9.5rem（窄屏 6.5rem），轨道 flex:1
深色模式发脏 --quickforge-workflow-done 从未定义，每次都在用 fallback 的浅色绿 在 :root / .dark 各定义 --workflow-done
缓动不生效 写了 var(--quickforge-ease, …)，但项目里叫 --quickforge-ease-out，每次都在用 fallback 14 处统一改为 var(--quickforge-ease-out)，并去掉多余的时间 fallback

05 · 复查方式

把右侧面板拖到 340px（最小宽）和 640px，看轴刻度与行标签是否保持同一字号——新实现下两者应完全一致。
