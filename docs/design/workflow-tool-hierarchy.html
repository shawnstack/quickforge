分组规则
  • 同一 Agent 之后、下一个 Agent 之前的连续 tool 合并成「工具调用 · N」，默认收起，头行右侧并列去重图标。
  • 只有 1 条时不分组，直接渲染单行（退化成方案 A）。
  • 组内有 error / running 时强制展开并高亮该行——折叠不能藏住故障。
  • 组头 hover 才出 chevron，静态保持安静；展开走 grid-template-rows + --quickforge-dur-base。
元素取值理由
阶段标题 11px / 600 / foreground 62% + 右侧 1px 渐隐细线 组织信息不抢内容，细线替代卡片框分隔阶段。
Agent 行 0.875×消息字号 / 500 / foreground 84%；meta 11.5px / muted 78% 唯一主行，任务名当标题；状态降级成 5px 圆点。
tool 行 0.72rem / muted 72%；参数 mono 11px / muted 52% 比 Agent 低一档，靠字号与颜色的双降表达从属。
tool 缩进 margin-left:6px; padding-left:10px; border-left:1px solid border/60% 复用 DESIGN_LANGUAGE 对「阶段内子级」的缩进+细连接线例外。
hover background: muted/50%，chevron opacity 0→1，dur-fast 不位移、不加阴影，符合「有感知不跳动」。
运行态 复用 .quickforge-tool-running-sweep 字形流光 不新增动效范式；组内 running 行随组展开可见。
失败态 名称转 --destructive，错误串缩进补一行 mono 危险色只出现在真实错误上下文，不预置红。
