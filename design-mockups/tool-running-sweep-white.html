工具运行态扫光 · 白色变体对比

现状实现是 color-mix(in oklab, currentColor 12%, transparent)：扫光颜色取文字色本身， 而工具摘要文字是 --muted-foreground。所以在浅色主题下它是「中灰带」，观感偏暗、像黑色； 在暗色主题下本来就是浅灰近白。下面把四种取值并排放在一起看。

A · 现状：currentColor 12%
随文字色变化：浅色=中灰，暗色=浅灰
运行命令 · npm run build
编辑文件 · src/index.css
B · 纯白 12%
深浅色都固定白色，浅色下几乎看不见
运行命令 · npm run build
编辑文件 · src/index.css
C · 纯白 22%
浅色下能看见一点点，暗色下明显更亮
运行命令 · npm run build
编辑文件 · src/index.css
D · 纯白 32%（极限对照）
暗色下偏刺眼，浅色下会像一块白斑
运行命令 · npm run build
编辑文件 · src/index.css
怎么看
  • 点「定格扫光」把动画停在正中间，强度差异更容易比较；关掉再点开可恢复滚动。
  • 浅色主题下白色扫光叠在白底上＝无效区域，只有压在文字笔画上才微微提亮；所以 B 基本等于关掉了动效，C/D 才会出现「白斑」感。
  • 暗色主题下 D 会明显发灰白，A 偏柔和——这也是现状在暗色看起来「已经是白色」的原因。
